# Project plugins

Record plugins used by either Claude or Codex here, including their purpose,
installation source, required permissions, and tool-specific enablement steps.
Do not vendor installed plugin caches into this repository.

Plugin directories use `shared-<name>`, `claude-<name>`, or `codex-<name>`.
Required manifest filenames inside a plugin keep their official names.

No project-scoped plugins are currently required.

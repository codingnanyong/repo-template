# Shared image asset rules

- Store references in `assets/images/source/`, working outputs in
  `assets/images/generated/`, and approved assets in `assets/images/final/`.
- Never overwrite a supplied source image.
- Use descriptive lowercase kebab-case names.
- Check crop, legibility, transparency, contrast, and file size.
- Keep material prompt or provenance details when needed.
- Do not publish or upload assets without explicit authorization.

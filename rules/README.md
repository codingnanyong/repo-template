# Rules

Rules define non-negotiable constraints for an artifact or work area. Prefix
each file with `shared-`, `claude-`, or `codex-`. A lead owner does not make a
rule tool-specific when both tools must obey it.

- `shared-documentation.md`: documentation quality constraints
- `shared-image-assets.md`: image lifecycle and safety constraints
- `shared-implementation.md`: implementation and verification constraints

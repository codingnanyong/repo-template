# Agents

Role definitions describe who owns a decision and which quality perspective to
apply. Use `shared-<name>.md` for roles available to both tools,
`claude-<name>.md` for Claude-only roles, and `codex-<name>.md` for Codex-only
roles.

- `claude-documentation-writer.md`: documentation owner
- `codex-image-creator.md`: image asset owner
- `shared-implementation.md`: shared implementer role
- `shared-code-reviewer.md`: shared review role
